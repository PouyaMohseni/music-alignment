# M1 — Monotonic cross-modal alignment (the "new path")

Reformulate score-following from per-frame heatmap segmentation (Henkel /
CB_TA / all B-series) into **differentiable monotonic sequence alignment**:
audio-frame × score-onset-column alignment matrix, forward-sum monotonic-path
supervision, beta-binomial prior bootstrap, monotonic-Viterbi decode. Targets
the confirmed #1 error mode (repeat-ambiguity, task #24) that a per-frame
classifier structurally cannot resolve.

## Locked design decisions (don't re-derive)
- **Columns = onset anchors** (ordered unique onset frames), NOT uniform spatial
  columns. Makes the path stay-or-advance-by-one + surjective (== validated
  `extensions/alignment/forward_sum.py`), and matches how eval measures error
  (at onset times).
- **Base = D1** (`mymodel/d1_align_matrix/`): reuse its MERT AudioTower + CNN/
  transformer ScoreTower verbatim (strip-format, self-consistent, NOT the
  strip-vs-native-page-contaminated path). M1 delta = gather score-column embeds
  at onset anchors + swap objective (dense-CE+soft-DTW → forward-sum + prior) +
  swap decode (DTW → monotonic Viterbi).
- Similarity `A@Bᵀ/τ` IS the alignment matrix (single-head cross-attn scoring);
  multi-head/learned-proj is a Phase-2 ablation, not needed to prove the method.
- Repeats: align to the **unrolled** score (`extensions/alignment/repeat_unroll.py`)
  so the path is monotone in both axes; fold back to printed strip for readout.

## Phases
- **Phase 0 — DONE (commit f3ab283):** `extensions/alignment/` {forward_sum,
  monotonic_decode, beta_binomial_prior, repeat_unroll}, GPU-free, unit-tested
  vs brute-force + gradcheck. `scripts/smoke_test_monotonic_alignment.py`.
- **Phase 1 — IN PROGRESS:** `mymodel/m1_monotonic/` (model.py, data.py) +
  `scripts/overfit_one_piece_m1.py`. Prove forward-sum drives the real two-tower
  model to the correct monotone alignment on ONE piece (loss halves, frame_acc
  > 0.90). Commit once it passes.
- **Phase 2 — full train + eval.** Build `mymodel/m1_monotonic/{train,eval}.py`
  (mirror D1's whole-piece loop + best-by-val-loss + early stop; forward-sum
  loss, annealed beta-binomial prior over first ~N epochs, Viterbi decode →
  onset-x → interpol_c2o timing, same pct@0.5s metric as everything else).
  `configs/m1_monotonic.yaml`, `train_m1.sh` (A100, warm-start pattern). Compare
  vs B1a (88.9%). **Add a repeat-stratified eval** (reuse
  `build_repeat_alt_cols`) isolating repeat onsets — where M1 should win and
  per-frame methods fail. That delta is the headline result, not just aggregate.
- **Phase 3 — robustness/uncertainty + real audio.** Calibration of the
  alignment posterior; multi-hypothesis behavior at repeats; then feed into the
  deferred real-audio test (task #38, ASAP/Magaloff/Zeilinger). Thesis eval
  section.

## Ablations worth running in Phase 2 (once base works)

on/off; onset-columns vs spatial-columns; multi-head cross-attn; DINOv2 score
tower vs D1 CNN (tiled tokens already precomputed at
`/scratch/pmohseni/dinov2_emb_tiled_native/`).
