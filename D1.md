# D1 — Dense Frame↔Column Alignment with Global Monotonic Decode

Status: proposed + first implementation. Supersedes the additive B-extension line
as the primary bet on beating CB_TA's 85.1% pct@0.5s, on the argument below.

---

## 0. Why this, and why now

CB_TA (85.1% SOTA) and every B/C extension so far share one decoder: an LSTM
whose hidden state is the *entire* memory of "where we are in the piece," decoded
per-frame into a dice heatmap. The residual errors of every model we have trained
are **drift errors** — mean tracking error is 3–20 *seconds*, i.e. the model gets
lost, not merely imprecise. Nothing in the per-frame-heatmap paradigm penalizes a
globally inconsistent trajectory during training, and the LSTM cannot recover from
a bad stretch except locally.

D1 attacks drift **structurally** rather than statistically:

1. Two-tower encoders (audio, score) produce a **similarity matrix** S[frame, column].
2. Trained so the matrix has a strong monotonic ridge at the true alignment.
3. Decoded by **DTW** — a globally monotonic path that *cannot get lost by
   construction* (the exact observed failure mode is impossible for a DP-optimal
   monotonic path).

This is the modernization of Dorfer et al. (TISMIR 2018, audio–sheet embeddings +
DTW), which lost to the UNet in 2020 for era-specific reasons now all resolved:
(a) MERT gives music-foundation audio features — already proven to transfer on
this exact data (v13 is our best trained model); (b) alignment-learning losses
matured in TTS (Glow-TTS MAS 2020, RAD-TTS forward-sum, Badlani et al. 2022) and
speech forced-alignment; (c) principled matrix-level path training now standard.
It is also the corrected instantiation of this repo's own README_main.md thesis
(MERT + vision tower + SoftDTW in a shared space) — CADP was a flawed version of
that idea (40px tiling → quantization ceiling, batch-size-1 gradient noise,
decoder trained inconsistently with the matrix); D1 fixes each of those.

Representation: the **unrolled horizontal strip** (224×W, single staff row,
x-axis position) — the same representation as our best models (v11/v13) and the
`eval_official` metric pipeline. The strip is genuinely 1-D, which is exactly what
makes monotonic DTW valid; this is why D1 uses strips, not CB_TA's native 2-D
portrait pages.

## 1. Data (fully consistent train = eval representation)

- **Scores**: `data/MSMD/cpjku_fmt/score/<piece>.npz` — strip `sheet` (224×W uint8),
  `coords` (N×3 = [y, x, height] in strip px), `onset_frames` (N, frame index at
  20fps per onset). All 354 train + 19 val + 94 test present.
- **Audio**: precomputed MERT-v1-95M embeddings, (T, 768) fp16 @ 20fps, keyed by
  whole-piece name.
    - test: `mert_emb_zenodo/cpjku_fmt_test_eval/<piece>.npy` (exists).
    - train+val: `mert_emb_zenodo/cpjku_fmt_wholepiece/<piece>.npy` (precompute_mert_trainval.sh).
- **GT column per frame**: from `_patched_load_piece` (eval_official) we get coords
  (x per onset), onsets (frame per onset), and `interpol_fnc` (frame → [y, x, h])
  and `interpol_c2o` (strip-x → onset time). Dense per-frame GT column =
  round(interpol_fnc(frame)[1] / column_stride_px).

Column geometry: score tower downsamples strip width by `w_downsample` (default 4),
so column index c ↔ strip-x pixel = c * w_downsample (+ half, for center). This is
FINER than the 10px GT box after /3 scaling — no tile-quantization ceiling (CADP's
fatal flaw was 40px stride, 4× coarser than GT).

## 2. Architecture

`mymodel/d1_align_matrix/model.py`

**Audio tower** (`AudioTower`):
- MERT emb (T, 768) → Linear(768→d) → 2× Conv1d(d,d,k=5,pad=2)+GELU over frames
  (local temporal context; MERT already carries long-range context from its own
  pretraining) → Linear(d→d) → L2-normalize per frame → A (T, d).

**Score tower** (`ScoreTower`):
- strip (1, H, W) → 3 conv blocks (1→32→64→d), each Conv2d k3 + GroupNorm + GELU;
  width strided by `w_downsample` total, height fully pooled (adaptive avg → 1).
- → (W_col, d) column sequence + sinusoidal positional encoding
- → `n_ctx_layers` (default 2) TransformerEncoder layers over columns (self-attention
  disambiguates visually-identical bars by global musical context)
- → Linear(d→d) → L2-normalize per column → B (W_col, d).
- Computed ONCE per piece (score is static), not per frame like FiLM.

**Similarity matrix**: `S = (A @ B.T) / temperature` → (T, W_col). temperature=0.07.

d=128, n_heads=4. ~1–2M params. Both towers gradient-connected through S.

## 3. Losses  (`mymodel/d1_align_matrix/losses.py`)

All on the matrix, where gradients reach both towers.

1. **Dense per-frame CE** (primary): for every frame t, softmax S[t,:] over columns,
   cross-entropy toward a Gaussian target centered at GT column c_t
   (sigma=`ce_sigma_cols`, default 3). This is strong dense supervision AND — because
   GT columns are monotonic in t — implicitly teaches a monotonic ridge. Avoids C1's
   geometry failure: the softmax lives only inside the loss, never in the decoded output.
2. **Banded soft-DTW** (path regularizer, weight `dtw_weight`, default 0.1): soft-DTW
   (Cuturi & Blondel 2017) over cost C = 1 − S, restricted to a Sakoe-Chiba band
   (`dtw_band` cols, default 80) around the diagonal for tractability — trains the
   exact object the decoder consumes (the best monotonic path's cost). Guarded for
   empty/degenerate reductions (the T=1 empty-`.mean()` NaN that bit B4/C2).

CE ~ O(log W_col) ≈ 6–7 at init; soft-DTW normalized ~ O(1). `dtw_weight` small so
CE anchors first, DTW refines — the loss-scale-balance lesson from B3 (whose 1.0
weight let an unbounded aux loss hijack model selection).

Gradient accumulation over `accum_pieces` (default 8) pieces before an optimizer
step — one step already sees hundreds of frame-level CE terms per piece (NOT CADP's
1-pair-per-step gradient noise), accumulation further stabilizes.

---

## 4. Decode  (`mymodel/d1_align_matrix/dtw.py`)

- **Offline DTW** (primary): standard DP over C = 1 − S, backtrack → path frame→column.
  Globally monotonic ⇒ cannot get lost. For each onset frame, read path column →
  strip-x px → feed `interpol_c2o` → identical pct@0.5s metric as eval_official.
- **OLTW** (Dixon 2005, causal online variant, `--online` flag): honest
  score-following (real-time, no future lookahead). Reported alongside offline for
  an online-tracking claim.

## 5. Training / eval

- `mymodel/d1_align_matrix/data.py` — `D1Dataset`: per piece, MERT emb + strip coords
  → (A_input, strip_tensor, gt_col_per_frame, valid_onset_frames, decode helpers).
- `mymodel/d1_align_matrix/train.py` — whole-piece-per-step + grad accumulation,
  ReduceLROnPlateau, early stop, checkpoint/resume (same discipline as v11).
- `mymodel/d1_align_matrix/eval.py` — build matrix + DTW decode → onset_diffs →
  pct@{0.05,0.1,0.5,1.0,5.0}s. Reuses eval_official's `_patched_load_piece` +
  `interpol_c2o`.
- `configs/d1_align_matrix.yaml`, `train_d1_align_matrix.sh` (A100, 24h, resume).

## 6. Why this can beat 85.1%, and the honest risks

Beat: SOTA's residual is drift; D1 removes drift by construction, on a
proven-stronger audio representation, with a training objective consistent with the
decoder. Ceiling becomes frame-level correspondence quality on synthetic
deterministic renders — which is high.

Risks: (1) offline DTW isn't causal — mitigated by reporting OLTW too. (2) repeated
musical material → matrix ambiguity — mitigated by score-tower self-attention + the
path loss. (3) precomputed MERT ⇒ no on-the-fly audio aug — acceptable for the MSMD
benchmark; extendable by precomputing augmented variants. (4) first run trains on
354 whole-piece strips (tempo-1000 only) — fewer sequences than the page×tempo set,
but each is a long densely-supervised sequence; expand to multi-tempo/page-level if
the first run shows signal.
